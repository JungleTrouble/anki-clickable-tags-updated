**Click a tag in the editor to see every card with that tag.**

In Anki's Browser, clicking a tag in the tag box normally opens it for renaming. With this add-on, **one click opens a Browser search for that tag**, so you can jump from any note to all of its related cards in one step. It's built for heavily tagged decks like AnKing, where one note can carry dozens of UWorld, NBME, Boards & Beyond and system tags.

### How to use

- **Click** a tag: the Browser shows every card with that tag, subtags included.
- **Double-click** a tag: rename it, the way a single click used to work.
- **Ctrl/Cmd-click** and **Shift-click** still select tags, and the trash icon still deletes.

It works wherever the note editor appears: the Browser, Add and Edit windows. From Add or Edit it opens the Browser. Inside the Browser it only changes the search. Unsaved edits to the current note are saved before the search runs.

Shortened tags like `...::WOMENS_HEALTH` are searched by their full name. Hover a tag to see the full name.

### Studying those cards

After clicking a tag, use **Edit → Create Filtered Deck** (Ctrl+G) in the Browser. It starts from the tag search you just ran.

### Good to know

- No setup and no card template changes. Install it and restart Anki.
- Read-only: it never changes your notes, tags or note types.
- Works the same on Windows, macOS and Linux.
- Requires **Anki 24.06 or later**. Tested on Anki 26.09.
- Clickable Tags Updated is a separate add-on written from scratch, not a fork of the original Clickable Tags. It works in the **editor**. For clickable tags on the **review screen**, see **Clickable Tags v3.0**. The two don't overlap, so you can use both.
